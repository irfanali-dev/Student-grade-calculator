# 🎓 Student Grade Calculator
A simple console-based Java application that calculates a student's total marks, average percentage, and final grade based on marks obtained in multiple subjects.

This project is designed for beginners who want to practice Java programming concepts such as loops, conditional statements, user input, variables, and basic calculations.

## ✨ Features
- 📚 Accepts a user-defined number of subjects.
- 📝 Takes marks for each subject from 0 to 100.
- ✅ Validates marks and rejects invalid inputs.
- 🔢 Calculates total marks obtained.
- 📊 Calculates average percentage.
- 🏆 Assigns a grade based on the percentage.
- 💻 Displays a formatted student result.
- 🔄 Allows the user to re-enter marks when the input is invalid.

## 📋 Grading System
| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–89.99% | A |
| 70–79.99% | B |
| 60–69.99% | C |
| 50–59.99% | D |
| 33–49.99% | E |
| Below 33% | F (Fail) |

## 🎯 Project Purpose
This project is created for learning and practicing core Java programming concepts. It can be used as a beginner-level Java practice project or a college programming exercise.
